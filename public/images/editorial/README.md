# Editorial raster assets

The raster assets in this directory were generated specifically for the twenty four solar term editorial redesign with OpenAI ImageGen. The four seasonal photographs were renewed on 2026-07-28 with brighter natural light and richer seasonal color.

They are:

1. `solar-spring-v2.png`
2. `solar-summer-v2.png`
3. `solar-autumn-v2.png`
4. `solar-winter-v2.png`
5. `article-shadows.png`
6. `paper-grain.png`

These checked in files are the visual sources for the redesign. Use the seasonal photographs full bleed, keep their central subjects safe when cropping, and preserve their natural color. The texture assets can continue to use their existing editorial treatment.
